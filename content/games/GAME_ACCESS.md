# 游戏乐园密码

入口：我的 → 打开家长中心 → 游戏乐园密码。按当前学习者保存设置，默认关闭；开启后统一保护数独、迷宫、扫雷和移植游戏。密码支持 4–32 个字符，可以是数字或文字。

首次设置需要验证账号登录密码。修改或关闭需要当前游戏密码；忘记时选择“用账号登录密码验证”重新设置。密码只保存为随机盐的 PBKDF2 SHA-256 摘要，接口不返回密码或摘要。

进入模块前验证；离开、账号切换或关闭页面后撤销本次许可。刷新首页和再次进入需要重新输入。服务器许可绑定会话、学习者与设置版本，修改密码后撤销全部旧许可；未撤销许可也有十二小时的最终有效期。五次验证失败后暂停验证五分钟。

保护范围包含目录、经典游戏脚本、移植游戏 HTML/JS/JSON/WASM，以及经典游戏奖励接口。静态文件在缓存校验前检查权限，禁止复用未验证的缓存；路径编码、目录入口与 HEAD 请求同样验证。离开时仍允许按原有账号校验保存游戏进度，避免重新上锁妨碍退出保存。

实现：`backend/game_access.py`、`frontend/game-access.js`、`frontend/game-access.css`。经典游戏 `puzzles.js` 改成解锁后加载。表在服务启动时增量创建，不修改既有账号或存档。

验证：`scripts/test_game_access.py` 启动隔离端口，创建临时账号与会话，运行真实 MySQL/HTTP 检查及 `test_game_access_browser.cjs`。覆盖配置、恢复、关闭、会话/学习者隔离、限次、直接链接、修改后撤销、错误/正确密码、经典游戏加载、手机布局与取消验证的异步竞态。结束后删除全部临时账号记录。
