# 故事素材

`chengyu-and-tradition.json` 是首次导入 MySQL 的素材文件。后端启动时会按稳定 `slug` 导入数据库中尚不存在的故事；已在管理后台修改的内容不会被素材文件覆盖。导入后以 MySQL 为内容的正式来源，管理页的增删改会直接写入 `stories` 表。

每篇包含稳定 `slug`、类型、适龄范围、摘要、分段正文、寓意、标签、预计阅读分钟数、封面路径和来源说明。封面采用 16:9 横向构图，与应用故事卡片和阅读页的横幅比例一致。`coverStatus` 为 `ready` 时，封面文件应已存在于 `frontend/assets/` 对应路径；`pending` 表示还未生成封面，可按 `coverPrompt` 补图后更新 `cover` 与状态。

正文为儿童适龄的原创白话改写。`sourceNote` 用于将来入库时保留典故出处和版本说明，不代表逐字引文。
