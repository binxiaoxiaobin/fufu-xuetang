# 朝代文字封面

2026年10月12日

原版采用按朝代知识点绘制的主题符号，例如秦的量尺、夏的河流，图形与朝代之间缺乏直接识别关系。新版19张封面改用“大字＋现代可读朝代名称”，保存于 `frontend/assets/learning/history/letters/`。书体说明在朝代详情的“封面书体”中查看。

秦采用现代小篆字体；西汉、新、东汉采用隶书风格；魏晋、隋唐等以楷书或行书参考；明以刻本风格参考。多个政权并存时不以单一字替代整个时期：三国并列魏蜀吴，南北朝并列南北，宋辽西夏金并列四个汉字名称。字体是现代演绎，不声称属于某位古代书家的原笔，也不把某种书体说成某朝独有。

夏没有可供本项目据以复原的完整文字体系，用现代楷书题名。商代甲骨字和西周金文字形资料已经找到，但源文件下载受限；当前两张封面使用后世篆书题名，明确不称为甲骨、金文原迹。可核对的原字资料：

- [商的甲骨文字形说明与授权](https://commons.wikimedia.org/wiki/File:%E5%95%86-oracle.svg)
- [周的西周金文字形说明与授权](https://commons.wikimedia.org/wiki/File:%E5%91%A8-bronze.svg)
- [中国国家博物馆：中国古代书法](https://www.chnmuseum.cn/zl/zlhg/201812/t20181220_32392.shtml)
- [中国文字博物馆：文字发展](https://www.wzbwg.com/fazhan)

实际使用的字体轮廓：

- LXGW Seal：作者提供的现代《说文》小篆字体，[项目](https://github.com/lxgw/LxgwSeal)，SIL OFL。完整字体和授权保存在 `tools/history-typefaces/`，未修改字体。
- Zhi Mang Xing：现代行书字体，[Google Fonts原始资源](https://github.com/google/fonts/tree/main/ofl/zhimangxing)，SIL OFL。完整字体和授权保存在相同目录，未修改字体。
- 本机隶书、楷体、宋体仅用于生成静态字形图；未复制、分发其字体文件。

网站加载的是字体轮廓组成的独立SVG图片，不需要访客安装字体或连接外部字体服务。名称旁保留可读的现代字，复杂古字、繁体字不会成为认识朝代的唯一线索。数据库只更新图片与书体说明字段，人物、事件、诗词与故事关联均保留；更新前数据备份位于 `artifacts/history/dynasty-covers-before.json`。

## 朝代简介补充

2026年10月12日，为19个时期补写了约184—225字的儿童友好导读，增加兴起背景、制度与生活变化、文化线索及转折节点；涉及年代争议和政权并存时，继续参照各卡的年代说明。正文清单保存在 `content/learning/dynasty-summaries.json`，`scripts/build_history_content.py` 会在重建目录时合并这份文案，`scripts/publish_dynasty_summaries.py` 只更新简介字段。数据库发布前的快照在 `artifacts/history/dynasty-summaries-before.json`。

随后把19个时期的“发生了什么”从每张2条扩充为3条，共57条；事件说明补上背景、过程和影响。40位人物的小传与贡献说明也已扩写，并继续保留原有诗词、故事关联。内容保存在 `content/learning/dynasty-event-expansions.json`，生成与发布分别由 `scripts/build_history_content.py` 和 `scripts/publish_dynasty_details.py` 处理；发布前数据库快照位于 `artifacts/history/dynasty-details-before.json`。编排参考[中国国家博物馆《古代中国》](https://www.chnmuseum.cn/portals/0/web/zt/gudai/default.html)的历史分期与展陈主题，人物和具体事件仍以各卡列出的史书、文物及专题来源为线索。
