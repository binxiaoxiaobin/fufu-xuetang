# 拼音真人读音与知识卡片排版

2026-10-09：替换 23 个声母、24 个韵母，共 47 段录音。

## 原问题

原实现用汉字交给普通 TTS 朗读。示例中的声调、声母呼读音和韵母独立音不一致，尤其 eng 对应“亨”、ong 对应“翁”，无法正确示范韵母。现在拼音页完全取消这条代读路径，也移除了原来的错误提示数据。

## 来源和存储

- 来源：SReading 拼音捷径，https://www.sreading.org/zh-hans/pinyin-pathway 。原网站说明为儿童提供声母、韵母真人录音；不宣称其具有国家级播音或教师认证。
- 下载镜像：https://github.com/zispace/hanyu-pinyin-audio/tree/data/sreading.org/pinyin ，保留原音频，不截取、不变速、不拼接。
- 原网站未声明开放许可，不把转载仓库视为音频的开放授权。数据库中保留真实来源及许可状态，未来公开商业发布前需落实录音授权或换为自有录音。
- 本地音频：frontend/assets/audio/learning-pinyin/，约 1.1 MB；ü 使用 v 文件名。
- 导入清单：content/learning/pinyin-cards.json；数据库 learning_pinyin_cards 关联 media_assets。
- 接口：GET /api/learning/pinyin-cards。前端按需请求，不在首页预加载录音。
- 导入脚本：scripts/import_pinyin_audio.py，私密输入 MySQL 密码，可重复执行。

## 交互与布局

按声母、单韵母、复韵母、特殊韵母、鼻韵母分组，卡片与末行居中。点击变绿并显示“正在播放”；结束恢复。切卡片、切页或进入后台停止播放。使用共享 Web Audio 手势解锁，兼容 iPad 在局域网 HTTP 下播放；加载失败不回退到汉字代读。

知识卡片选项卡居中；乘法表放入居中的浅色区域，保留直角三角排列。手机可以在表格区域横向滑动，页面本身不横向溢出。
