## 自动续期

`fufu-certbot-renew.timer` 每六小时检查一次，随机延迟最多 30 分钟，补执行错过的任务。任务由 `fufu-certbot-renew.service` 调用 Certbot，只续期 `fufu-ip` 证书。续期后由 `/etc/letsencrypt/renewal-hooks/deploy/fufu-nginx` 检查配置并重新加载 Nginx。

正式续期检查执行成功，续期模拟测试（包含部署钩子）也已通过。正式证书以外的测试证书仅保存在服务器私有备份目录中，没有配置给网站使用。

## 公网验证与 HTTP 跳转

腾讯云轻量应用服务器防火墙已添加 TCP 443 入站允许规则（来源全部 IPv4 地址，备注“福福学堂 HTTPS”）。服务器 UFW 也已允许 TCP 443。公网验证通过：HTTPS 首页返回 200，`/api/health` 返回数据库正常，HTTP 首页返回 308 并跳转到 HTTPS。

最终访问地址：`https://106.53.96.154/`。Nginx 的公开 HTTP 监听会跳转至 HTTPS，ACME 验证路径仍通过 HTTP 提供服务以支持自动续期。原有 SSH 本地后台入口 `http://127.0.0.1:18080/admin` 已验证返回 200；公开的 `/admin` 仍返回 403，后台访问限制保持有效。
