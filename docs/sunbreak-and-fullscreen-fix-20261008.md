# 赛车旧入口修复与晴山飞驰接入

## 打不开的原因

服务访问日志在 2026-10-08 12:01:32 显示卡丁车从旧玩具入口打开，地址带 `?v=20261006-2`。旧入口会立即嵌入 iframe，没有请求全屏；卡丁车的新版入口要求父页面为全屏，因此只显示拦截提示。原来的加载遮罩又遮住了这个提示。此路径尚未启动 WebGL，不能将这次打不开归因于渲染性能。

修复了已打开旧页面的兼容：游戏入口会隐藏旧遮罩，给出明确的“全屏开始”；只能在用户点击并成功进入原生全屏后导入游戏代码。新旧两种入口均支持退出全屏卸载，直接游戏地址仍禁止启动。新版首页、懒加载目录和适配入口也更新了资源版本。

## 新游戏

原作：[SUNBREAK / Imirushik](https://github.com/Imirushik/sunbreak-downhill-3D-game)。仓库没有 LICENSE，package.json 也没有 license 字段，当前按用户请求完成本地适配，保留作者与来源记录，不能按 MIT 或其他许可对外分发。发布前应取得授权。

原始代码在 `content/games/sunbreak/source/`，下载校验在 `provenance.json`，适配触屏入口与样式在 `adaptation/`。准备脚本在 `scripts/prepare_sunbreak.py`，开发依赖及构建暂存目录是 `artifacts/sunbreak-build/`，应用版本在 `frontend/assets/games/sunbreak/`。游戏无运行时 CDN、模型下载或外部服务，主程序压缩传输约 168 KB，说明页面不导入三维程序。

目录沿用 MySQL 的 `toy_games`、`media_assets` 与 `/api/toy-games`。元数据在 `backend/seed_data/sunbreak_game.json`。没有改动题库、旧游戏存档或学习积分。比赛最佳成绩与幽灵轨迹暂保留原作的本机存储，当前不奖励学习积分。

中文玩法、暂停/继续/重开、触屏转向、踩踏、刹车、蓄力后松手跳跃、冲刺与 7 种空中特技已接入。按键支持多指同时操作、松手、取消、失焦与暂停清理；键盘操作触屏按钮不再冒泡触发全局开始键。结果界面改为已完赛骑手按用时排序，未完赛者按距离排序。

触屏设备默认轻量画质，像素比上限 1；桌面上限 1.5。保持一致的种子地形，避免跨设备幽灵轨迹与路线不一致。隐藏页面暂停模拟、渲染和音频，返回后比赛保持暂停；离开游戏释放渲染目标和音频。仍需支持 WebGL 2 与原生页面全屏，实体 iPad 帧率和多指手感尚未实机测量。
