# 记忆拼拼

首页“学习小工具 / 认字与单词快练”增加独立入口。使用现有MySQL词库及本地录音，五类内容为英语单词、单个汉字、中文词语、英语句子、中文句子。默认认识起步，可自主选择主题和难度，不按年级限制。

完整预览由孩子决定看多久，点“记住了，砰！开始拼”后立即移除预览、拼音、释义及预览朗读入口。字块从中央散开，只留下通用空格，没有文字影子、长度不同的字母轮廓或包含答案的辅助标签。拼字阶段可以任意放置字块，直到主动检查才核对顺序；错误位置标出并可拿回调整，不扣分或计时。“再看一次”清空拼写并回到完整预览。

中文按字、英文单词按字母、英文句子按完整词分块。词间空格和句末标点不是要拖动的字块；最终显示原始完整句子及标点。重复字块有不同ID，核对用字块文字而不是ID，避免相同字母交换后误判。

沿用现有读词quiz session、1分完成奖励及重复提交保护；完成页朗读整词/中文意思或整句，可换内容继续。页面退出通过readerCleanup中断拖动和事件，并取消整条声音播放；等待保存时的回调沿用quizViewGeneration保护。记忆形式的内容没有再造一套静态词库。

测试：test_reader_memory.cjs检查中英文分块、短语空格及重复字母；独立DOM测试检查五个纯空格、错误字母可以落位、拼错提示、撤回更正和完成、中文句子及手机宽度。test_speech_exit.cjs检查声音退出保护。当前浏览器的正式页面要求重新登录，因此独立预览不写入积分，正式登录状态下的入口与积分整轮需再验收；实际iPad拖动需真机体验。
