# 游戏乐园整理与汉化

游戏目录按数据库 `collection` 分类：`small-3d` 对应六款桌面玩具游戏，`adventure-3d` 对应海岛卡丁车、晴山飞驰。原有五款经典游戏移入直接展开的“轻松小游戏”区域，保留原有控件、成绩、积分和操作逻辑。顶部分类入口只滚动到对应区域，不改页面路由。

海岛卡丁车：汉化车手、选车、赛车类型、难度、键盘说明、圈数、名次、漂移等级、成绩、提示、赛道横幅和围栏招牌。晴山飞驰：汉化骑手、九段路况、检查点、分段计时、特技、比赛结算、暂停说明、天气画质工具、无障碍标签和起终点招牌。键盘字母是实际键位；来源链接与许可原文保留，游戏内的功能说明采用中文。

原下载源码保持原样；`scripts/game_localization.py` 对两款游戏的本地构建应用严格的显示文本补丁。特技物理标识、键位标识、存档键不变，避免破坏动作与历史成绩。汉化菜单和图片使用新版本地址，卡丁车的内部模块引用也带版本，避免浏览器复用旧菜单。

中文封面来自实际游戏截图，放在 `frontend/assets/games/` 的各游戏目录，并在 `content/games/` 保留构建输入。来源、许可、封面、分类和入口继续由数据库加载。两款进阶游戏仍在成功进入原生全屏后才创建游戏页面，退出或返回后卸载。

验证：两款游戏的全屏入口、选车/主菜单、实际比赛、暂停、退出；经典数独切换；1024×768、768×1024 分类布局无横向溢出。自动检查涵盖多点触控、跳跃松开、模态/全屏释放、旧入口兼容、汉化 HUD 的实际结果输出、名次与本地模块依赖。山地骑行通过类型检查和生产构建。尺寸检查使用浏览器，尚未做实体 iPad 的帧率测试。
