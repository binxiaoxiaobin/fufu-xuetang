# 战役与三十六计 · 第一版

2026年10月11日

## 已发布内容

语文卡片增加“著名战役”和“三十六计”，沿用原有朝代时光轴，并在原有后台的“学习卡片”中管理。

著名战役共12场：牧野、桂陵、马陵、长平、巨鹿、垓下、官渡、赤壁、淝水、崖山、靖难、萨尔浒。按年代排列，包含年份、地点、背景、经过、影响、相关人物简介、阅读辨析、思考问题及资料出处。人物简介覆盖31位人物，重复出现的人物采用一致介绍。古文阅读先配于巨鹿、垓下、赤壁三场。

三十六计全部36计，按胜战计、敌战计、攻战计、混战计、并战计、败战计分组。每计包含计意讲解、实例与辨析、文言节选、字词解释、白话翻译、思考问题及原典链接。假设实例明确标注，史实与演义分别说明。

## 内容关联

- 卡片可跳到相应朝代；朝代详情展示关联战役和计策，并可跳回卡片。
- 桂陵与围魏救赵、官渡与釜底抽薪、赤壁与苦肉计及连环计等可相互阅读。
- 计策关联朝代是按战例或阅读主题建立，不意味着该书在对应时代已经成书，也不意味着古人使用这个计名下令。
- 与既有人物库同名的人物可以通过朝代详情继续阅读现有故事和诗词，例如曹操的小传和《观沧海》。新人物简介保存在战役卡片中；本版没有为每一位人物另写独立故事或诗词。

使用内置图像生成工具生成两张史诗风格的栏目主题图，分别用于战役和计策目录。它们是共享主题图，不是48张独立配图，也不是某场战役的史实复原。

## 后台与更新

在原有后台“学习卡片”中选择对应栏目，可修改正文、古文、解释、人物介绍、配图路径、朝代和卡片关联，或归档内容。保存后前台重新打开即可读取，无需重启服务。数据存入数据库，初始化只补充缺失内容，不覆盖后台修改。保存使用版本检查，避免旧编辑覆盖新编辑，并复用现有权限和审计。

验证48张卡片数量、关联完整性、图片文件、古文必需字段、保存即时读取、初始化保留修改、旧版本冲突和非法关联拒绝。现场验证了原有后台保存、赤壁→苦肉计→东汉→赤壁的跳转、36计目录和分组筛选。手机与平板实际页面没有横向溢出。
