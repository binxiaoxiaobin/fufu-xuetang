# 海岛卡丁车接入记录

来源：[BridgeMind / Turbo Kart Rally](https://github.com/bridge-mind/turbo-kart-rally)，MIT 许可。上游原始代码留在 `content/games/turbo-kart-rally/source/`，下载归档 SHA256 在同目录的 `provenance.json`。应用版本和 Three.js 0.170.0 的必要依赖放在 `frontend/assets/games/turbo-kart-rally/`，保留两份许可文件。无运行时外网字体、模型或 CDN 依赖，应用文件约 1.3 MB，文本由现有后端压缩传输。

游戏目录沿用 MySQL `toy_games` 和 `media_assets`，通过 `/api/toy-games` 加载封面、名称、玩法、来源、许可和 `fullscreenRequired`。没有改动旧游戏存档、题库和用户积分。当前赛车比赛不计积分；选车、难度和圈数使用原作本机设置，比赛中途不存档。

点击游戏卡片只打开玩法说明，没有 iframe 或 WebGL。用户点击“全屏开始”并成功进入原生页面全屏后才加载游戏。拒绝或不支持全屏时保持说明页面；退出全屏、切换页面或切换账号会移除 iframe，结束本局并释放场景。直接访问游戏入口也无法启动。旧 WebKit 全屏事件兼容；不将普通铺满页面伪装成原生全屏。

触屏驾驶提供方向、加速、刹车、漂移和道具，支持多指同时操作、长按反馈、取消和失焦释放。暂停、重开和继续使用中文按钮。默认简单 50cc、1 圈；另有 100cc / 150cc 和 3 / 5 圈。原作目前只有一条棕榈湾赛道，没有声称新增赛道。

触屏设备像素比上限 1，不建立后处理渲染目标，关闭实时阴影和抗锯齿；桌面上限 1.5。隐藏标签页暂停模拟、停止绘制并挂起音频，返回后比赛留在暂停状态。需要支持 WebGL 2 和页面全屏的浏览器。

验证：

- `scripts/test_kart_integration.cjs`：实际输入控制器的多指组合、松手、失焦清理、道具单次触发；全屏等待期间不加载、退出卸载、拒绝处理、导航取消、全部模块本地依赖解析。
- 浏览器：目录读取数据库、全屏启动、选车开赛、长按加速从 0 到 130 km/h、暂停/继续、松手回到 0、退出后无 iframe；直接地址显示全屏入口说明。
- 1024×768 与 768×1024 入口无横向溢出，开始按钮 48px；全屏实际效果图在 `artifacts/turbo-kart-fullscreen.png`。
- 服务继续监听 `0.0.0.0:8000`。尚未在实体 iPad 上测量帧率和耗电，需用目标平板验收多指手感及 Safari 全屏支持。

维护：`scripts/build_turbo_kart.py` 重新生成适配后的上游 `src`、本地 Three.js 依赖和封面，独立的 `fufu-kart.js/css` 与入口不会被覆盖。升级上游先在保留归档的条件下检查 API、许可证和上述验证；不要直接用上游入口替换应用全屏门槛。
