# 字词快练：小组、换序、回想

记忆拼拼已并入首页的识字快练与单词快练，不再有独立首页卡片和独立目录。共用主题、难度和数据库词库。默认认识起步，每组5个，也可选择3个；主题不足时按实际数量练习，不重复凑数。

拼法可选“看着拼”与“记住再拼”。字词和单个汉字支持两种拼法；整句自动切换记忆拼法。英文句子按词分块，中文按字分块。三环节始终围绕同一组词语：先整组拼写，再整组选词，最后整组听音。每环节重新排列，保证字词换位置；3个及以上时也避免前一环节最后一个词立即成为下一环节第一个。不是跨天间隔复习系统。

选词及听音优先以组内其他词作候选，不足两个时补用原数据库干扰词。完成页列出整组词语、完整读音及需要巩固的词；巩固可按错误词集合重新开始小组。返回主题会结束当前互动与语音；未完成的组不提供刷新后续练。

后端 reader_unit_ids 接口一次创建1至5个同学科、不同且已发布的字词。兼容原 reader_unit_id 单词接口。已有会话成员校验和重复答案保护继续生效。前两环节由前端验证、不发积分，最后听音答对时每词1积分和一条既有答题积分日志，完成整组后关闭会话。后台仍以词汇题为积分单元，不单独记录每次拼字或三个阶段的事件。
