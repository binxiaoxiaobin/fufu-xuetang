# 快练界面与自动完成

默认页面只显示识字/单词切换、开始学/待巩固/新字词/已记熟的范围切换、生活主题和开始按钮。难度、每组题量、最后记忆内容及指定练习组收进默认折叠的“调整练习”。主题改为轻量文字按钮，不重复放置主题图标和下拉筛选。

快练内主按钮统一森林绿，语音和次操作统一浅色边框，字号、圆角、触摸尺寸、焦点反馈一致；字块与答案继续保留绘本画风。第三步答案按钮不做循环动画。选对后读目标词，不自动重读刚听过的完整句子。

音频预加载和播放共用同一个进行中的下载/解码请求，避免重复获取。快练Web Audio播放跳过录音边缘的低幅度静音，起始保留80毫秒、末尾保留100毫秒余量。其他模块录音不裁边，音频元素兜底保留原录音边界。

第四步放满字块自动检查：正确就提交并进入完成反馈，最后字母读完后自动接上完整词与中文录音，不等待积分保存。每次拼写成功只自动播放一次，保存重试不会重复朗读；只有点“听完整读音”才手动重听。错误字块仍可拿回来调整，只有保存失败才出现重新保存按钮。

验证：自动填满检查、延迟保存期间先读词、最后字母衔接、单次自动播放、退出后取消、静音边界、原有句子先读后选及生熟词筛选测试通过。独立浏览器检查完成筛选展开/折叠和四环节，第四步无需点检查即可完成；积分和标记使用模拟数据，不修改学习账号。未在真实iPad上测量帧率。临时检查页已删除。
