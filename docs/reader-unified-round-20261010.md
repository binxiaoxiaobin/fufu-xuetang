# 字词快练：统一四环节

当前流程为同一组看着拼 → 换序听音辨词 → 换序句子选词 → 换序记住再拼。旧的两种拼法切换已取消。每组最多五个，可选择三个轻量练习。每个词在最后记忆拼写成功时提交一次答案，奖励一积分；服务器继续负责重复提交保护。

句子环节播放现有数据库对应的完整句子录音。声音未结束、被中断或播放失败时不开放选择；可以重听。退出后的异步回调不会重新开放旧页面。

选词参考人教社识字教学建议（https://www.pep.com.cn/bks/xxyw/jzjd/202512/W020251202575246044880.pdf）中的常用、生活语境、整体认字，以及 EEF 词汇教学建议（https://educationendowmentfoundation.org.uk/early-years/evidence-store/communication-and-language/teaching-and-modelling-vocabulary）中明确介绍词义、在语境中使用词汇的原则。

核心组人工指定教学目标：身体、家庭、餐桌、书包、天空、常见水果，以及英语短词拼写。其他词按主题、难度和单字/词语整理为扩展组；中文长词、部分复杂单字与英文长词提高组难度。这是应用内的编辑规则，不是权威字频排序或完整自然拼读课程。单字回想加入本组已练过的其他单字，避免只有一个可选字块。词组元数据随现有 source_metadata 发布至 MySQL，前端从接口读取，不依赖前端硬编码词表。所有618项保留。

轻量组优先选择组内尚未练过的词。已增加按学习账号保存的生词/熟词标记，见 [记忆标记说明](reader-memory-status-20261010.md)；尚未实现自动间隔复习算法。

验证：四环节顺序/边界不重复、分组覆盖、录音完成前锁定选择、重播/中断/失败/退出保护、字母及完整词读音、退出语音停止、数据库积分及重复提交保护均通过。独立浏览器检查页用真实资源完成三个英文词的十二个活动；测试积分为模拟，未写入账号。实际学习页面当前存在管理员账号登录提示，因此未以真实学习账号走完整流程。检查页已移除。
