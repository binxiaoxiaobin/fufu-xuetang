# 支持者共创花园

入口：`/community.html`；家长中心和首页页脚有链接。管理入口：原后台 `/admin.html` 左侧“共创社区”（直达 `/admin.html#community`）。共用原后台登录与权限；旧 `/community-admin.html` 地址仅跳转，不再提供独立管理界面。

## 身份与隐私

登录账号保留原有规则（允许手机号或普通账号），另建账号级社区昵称，不复用登录手机号、后台 display_name 或孩子昵称。默认随机花园昵称，可修改独立昵称和预设头像。公开接口使用明确字段白名单，不输出账号 ID、手机号、登录名、支付流水。昵称禁止连续七位以上数字及邮箱形式。社区内容须人工审核，避免用户自行泄露隐私。

默认不上榜、隐藏金额。榜单展示须主动同意，可随时关闭。公开排名仅在自愿上榜且账号正常的支持者中计算；按累计已确认且未退款金额降序、达到该金额时间升序、账号 ID 升序。前 100 名展示榜单；前 3 名分别为糖果之冠、银糖之星、暖糖之星，第 4–100 名为百强共创者，其余有支持记录者为暖心支持者。帖子及评论动态读取当前昵称和徽章。排名更新，不将旧排名固化在帖子中。

## 支持与权限

档位：99 分（请团团吃颗糖吧）、990 分（请糖糖吃块蛋糕吧）。金额在服务端固定，不接受用户提交的售价。

当前支付未接通，不显示收款码、不扣款、没有自动支付回调。可以创建/取消待支付订单，相同账号、档位的待支付订单复用。订单保存不授予权限。任何普通用户均不能将订单改为已付款。

本机超级管理员可在合法适用的实际收款渠道核实到账后登记金额、渠道和真实流水。金额必须与订单一致，流水唯一并保留于退款后，防止复用；重复确认同一笔收款不重复开通。审核操作写入现有管理审计日志。登记退款仅更新系统记录，管理员必须先在实际渠道完成退款。

每笔已付款且未退款订单授予到账后 365 天发言资格，多笔订单取最长有效期，不累加年数。每月 3 篇帖子、每月 10 条评论，待审核及隐藏内容同样计入额度。付款金额不增加额度或建议优先级。有未退款支持记录的标记不因资格到期消失。退款后按剩余有效订单重新计算权益；原公开内容不删除。并发额度通过锁定账号行后检查、写入保证。

## 内容管理

任何人可匿名浏览公开内容，账号登录后支持者才能发言。建议/分享、评论默认待审核；后台可公开、隐藏、回复及设置待评估/已计划/开发中/已完成/暂不采纳。已隐藏帖子的详情及评论不再公开。作者可查看最近 20 篇投稿状态。公开帖子和评论以游标分页；后台内容/订单/举报分页。家长账号可限额举报，后台可处理及禁言/恢复；付款不绕过禁言。

接口要求同源 JSON 写入；管理 API 沿用本机限制和管理员角色。超级管理员管理款项，超级/内容管理员管理内容。所有用户文本在浏览器转义为纯文本展示。

## 正式公开运营前尚需配置

- 按实际主体、类目申请适用的微信/支付宝商户产品及正式退款、客服条款。接入官方订单支付、验签回调和主动查单，不能靠截图或客户端“付款成功”开通。
- 现有账号是账号密码登录，尚未实现短信实名认证。公开评论所需身份认证需另行接入合适服务；账号填手机号不等于已经验证手机号。
- 社区目前为本地开发版本。隐私告知、内容审核人员、举报及申诉联系入口、备案/许可和游戏版权及发布边界，按实际公开运营方式落实。学习内容免费不自动消除授权限制。
- 数据库存储时区沿用当前 MySQL 设置；额度按数据库当地日/月计算，部署时统一为 Asia/Shanghai。

验证：`scripts/test_community.py` 使用临时账号和真实 HTTP/MySQL 检查隐私、金额篡改、权限、到账幂等、退款、审核/举报、并发额度以及前 100 徽章边界，最终清理全部测试数据。

账号管理：超级管理员可在账号列表查看有效支持金额、未退款支持次数和共创资格；详情展示社区昵称、累计到账、退款金额、最近到账及资格有效期。统计由 community_orders 关联 account_id 汇总，金额以整数分保存，待支付与取消不计入，退款扣除有效金额，过期不扣除历史支持金额。其他账号管理角色不返回财务汇总。

分享共创：每个注册家长账号有唯一12位分享码，历史账号访问社区时自动生成。专属链接 community.html?ref=分享码；分享码只在新账号注册事务内绑定，已有账号不能补领。邀请1个有效新账号后资格365天，重复邀请更新有效期但不叠加额度。月度3帖/10评论与支持资格共用。分享徽章独立于支持及金额榜。邀请账号停用后不计入有效邀请；社区禁言同时停止两类发言资格。新建 community_share_codes 与 community_referrals，邀请记录绑定双方 account_id。当前注册未接短信实名核验，无法完全区分真实家庭与刷号，正式推广前需加强注册验证。

后台数据调整：超级管理员可在人员详情为支持金额、成功邀请人数增加或扣减修正值，必须记录原因并写入操作日志。原始已到账订单和真实邀请记录保持不变，修正独立存入 `community_admin_adjustments`；有效支持金额包含修正并反映到支持榜，金额修正不会伪造付款或更改发言资格；邀请人数修正有365天期限并可调整分享发言资格。不可将金额或人数修正到负数。人员详情保留最近50条调整记录。
