# 配图放大与教材目录恢复

诗词阅读窗由 650px 放大到 720px，配图取消原来的 500px 上限，仍保留完整比例。渐变从图片上方 28% 处开始，逐渐过渡到米白色；标题向上叠入底部渐变。列表改为最多四列，配图面积随卡片适度增加。手机仍为两列，无图片的科学卡片不使用叠图标题。

教材内容为空的原因：当前孩子为幼儿园中班，而接口使用孩子的阶段筛选小学教材，返回空目录。题库没有被删除。教材目录现在按固定小学阶段和用户选中的年级读取，教材练习的阶段、年级由可信的教材目录决定；常规练习仍使用孩子原来的阶段、年级，不修改个人资料。

验证：`scripts/test_curriculum_stage_access.py` 使用临时幼儿园、小学资料验证每阶段 32 册教材、共 64 次知识点练习，检查题目数量、练习阶段与年级、日常练习和无效目录拒绝；测试写入全部回滚。结果保存为 `artifacts/curriculum-stage-access-verification.json`。已有登录页面实际恢复单元、知识点和题量。

页面检查覆盖 768×1024、390×844：完整配图、原文和释义切换、文本可读性、页面及弹窗无横向溢出。实际设备的 Safari 体验需实机确认。

本地已通过 `scripts/reload_existing_backend.py` 将更新后的 HTTP 代码加载到 0.0.0.0:8000，使用已初始化数据库，未重导其他内容。
