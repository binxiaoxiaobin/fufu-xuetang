# 字词记忆状态与语音衔接

第四步放入英文单词的字母时读字母名称；拿回后再次放入也会发音。完整词语与中文读音仍在拼写成功后播放。所有快练录音以1.05倍速度播放，使用原录音音色；预加载当前词的单词、句子及中文录音，连读时提前准备下一条。其他模块保持原播放速度。

每个学习者的状态写入MySQL的reader_progress表，主键为learner_id和question_id。GET与POST /api/learning/reader-progress均要求有效学习账号，学习者ID由登录会话解析，客户端不能选择他人的ID。发布字词完成后才允许标记review/mastered；无额外积分。历史成功练过但未标记的字词在启动时导入为待巩固，不自动认定为熟词。

完成总结页默认为“还要练练”，可自行标记“已经记熟”。保存有等待、成功和失败反馈，串行写入避免较早请求覆盖新选择。默认只选新词与待巩固，优先待巩固；熟词不再自动出现，仍可通过“已经记熟”分类重新练习并改回待巩固。这是自主记忆标记，不是已经实现的自动熟练度评分或间隔复习算法。

验证包含第四步字母读音与重复放置、播放速度隔离、熟词排除与分类、数据库状态转换与学习者隔离、无练习记录的非法标记、旧有语音取消及积分保护。独立浏览器检查使用真实页面组件、录音和模拟积分/标记，走通四环节、保存熟词、默认排除与熟词查看，不修改真实账号。临时检查页已移除。
