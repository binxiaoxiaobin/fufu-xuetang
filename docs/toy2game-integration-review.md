## 建议的接入方式

上游游戏是独立 HTML 入口，使用 Three.js；原大厅通过链接进入游戏。建议学堂只引入选定游戏，采用按需创建的同源 iframe，复用现有游戏乐园外壳。此方式是本项目的接入方案，不是上游当前实现。

- 构建资源规划放入 `frontend/assets/games/toy2game/<game-id>/`，含该游戏入口、脚本和素材；版权与第三方声明随资源保留。调整构建基础路径，避免根路径、重复字体和版本不同的 Three.js 混用。[上游构建脚本](https://github.com/asmoyou/toy2game/blob/39078515a13331a748e63bc75424ed83c773a72a/scripts/build.mjs)
- 游戏标题、简介、封面路径、入口路径、适龄信息和来源写入数据库目录；首页只读目录。关卡与进度按学员加载，服务端提供分页或单关接口，避免首页加载全部关卡和三维资源。
- 原游戏存档存在当前浏览器，需要适配为按学员保存的 MySQL 进度。浏览器只保留短期缓存；断网状态不要提示“已同步”。[移车存档实现](https://github.com/asmoyou/toy2game/blob/39078515a13331a748e63bc75424ed83c773a72a/games/parking-escape/src/storage.ts)
- 新游戏不能直接复用现有奖励接口：当前后端只接受五款旧游戏。建议增加服务端挑战记录、结果校验、重复请求防护和每日奖励上限；移车游戏可以用关卡初始状态及合法移动序列验证过关。初期积分数额另行确定，不与稻田奖励混用。
- 退出游戏时释放 iframe、音频和渲染资源，切后台暂停。移车原场景使用最高 1.75 的像素比和 2048 阴影贴图，建议在平板先降低画质、限制阴影更新，避免与团团场景同时持续渲染。[移车场景实现](https://github.com/asmoyou/toy2game/blob/39078515a13331a748e63bc75424ed83c773a72a/games/parking-escape/src/scene.ts)
- 分批验收：先完成单款接入、数据库保存和触摸操作，再验证横竖屏、返回、刷新恢复、账号切换、重复奖励、音频停止和连续切换的资源释放。必须补真实 iPad Safari 测试。

## 本次牧场修复

1. 普通局域网 HTTP 缺少 `crypto.randomUUID()` 时，改用兼容的操作编号生成方式，仍符合后端重复请求校验。
2. 喂草、摸摸、播种、浇水等直接请求服务器，不再因为寻路失败或等待走近而无法执行；“去看看”保留为独立场景操作。
3. 小羊名字牌、牧场牌和稻田牌可点击，触摸允许在牌子附近选择。轻微手指移动不再立即判定为拖动；双指缩放、取消触摸不再触发点击。
4. 面板缩减重复信息，常用按钮前置；显示下一步、当天照顾状态和各分区玩法流程，提供展开的说明。
5. 所有面板按钮至少 44px，输入框 16px；滚动和说明展开状态在自动更新时间时保留，避免控件反复重建。
6. 请求超时会恢复操作，并提示重新打开确认结果。兼容不支持 Canvas roundRect 的旧绘图环境。

牧场数据和规则继续从现有 MySQL 接口加载；30 天基础生长周期、每天最多浇水一次、每次最多提前 6 小时、每轮收获 12 积分保留。没有引入新的经济规则。
