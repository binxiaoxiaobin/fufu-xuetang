# 常用字词扩充与双语读音

本轮内容为中文308个字词、英语310个单词或常用短语，共618组，新增310组。主题仍是水果、蔬菜、食物饮品、生活用品、身体衣物、动物、自然、交通、动作、位置描述、朋友表达，不按年级划分。内容来源为项目原创 reader-more-common.txt，每个词含释义、完整例句、分类和难度。较长英语词按拼写长度提高难度；中文已有的彩虹、种子与新英语词对应时复用概念，不创建重复中文题。

已事务发布。1546个音频引用对应1276个本地文件，全部通过MP3解码检查；中文名与中文词共用相同录音。数据库测试验证了308/310的数量、新题创建和双语音频关联，临时测试积分已回滚。

拼写结束提供“再听完整词”按钮。英语最后一个字母读完后，用同一个可取消的录音序列播放完整英文和中文意思；中文播放完整词语。听音辨词阶段只读当前目标词，不自动加入中文。完成页也可以重听双语词和整句。新增translation / translation_audio / translation_asset_id存入题目数据库元数据；录音按shared speech_config的晓晓和Jenny配置生成，统一音色和语速。退出练习停止整条播放序列。

选词按钮采用与拼字相同的黄、绿、粉色字块、轻微倾斜和小表情，正确答案有微笑和落位反馈；听音按钮是带小耳朵的声音伙伴。触摸控件高于44px，长词换行并适配窄屏；英语短语在词间显示空隙，不要求孩子拖动空格。

构建与发布：build_reader_lessons.py → generate_reader_audio.py → publish_reader_lessons.py，迁移版本reader-common-20261010-v10。旧题号及现有音频保留，新题沿用稳定题号。新练习不生成已经退出展示流程的插图；原有图片及媒体关联保留。音频同文本同音色共用内容摘要文件，并通过每文件异步锁避免英文释义与中文词重复生成同一个临时文件。每完成三步仍只奖励1分。

验证包括题号及词语唯一性、句子模板、候选项、完整音频文件可解码、录音与数据库关联、新旧练习创建、积分和重复提交回滚测试。test_reader_letter_speech.cjs核对最后字母与完整词的顺序和双语URL顺序；test_speech_exit.cjs核对双语播放与退出后没有续播。浏览器检查了完整词按钮、选词与听音页面、重复字母和手机宽度。实际iPad的触摸和声音仍应以真机体验为准。
